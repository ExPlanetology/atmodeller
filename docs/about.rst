About
=====

*Atmodeller* is a Python package for thermochemical equilibrium modeling of planetary interiors and atmospheres, built on `JAX <https://docs.jax.dev/en/latest/>`_. It is released under `The GNU General Public License v3.0 or later <https://www.gnu.org/licenses/gpl-3.0.en.html>`_. Community development is strongly encouraged. If you use *Atmodeller* in your research, let us know and we'd be happy to include your work in the :ref:`Used In <UsedInFile>` section. This will help us track the impact of *Atmodeller* and also provide a resource for users to see how it has been applied in practice.

Citation
--------

If you use *Atmodeller*, or data from *Atmodeller*, please cite :cite:t:`BTH25`. In addition, please consult the *Atmodeller* source code for citations related to specific model components, such as solubility laws and real gas equations of state. Thermodynamic data are sourced from :cite:t:`MZG02`.
