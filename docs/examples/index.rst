Examples
========

These examples demonstrate how to use *Atmodeller* to model a variety of planetary interior-atmosphere interactions. Start with :doc:`basic_usage`, which introduces defining species, setting up and solving a model, accessing the output, and batching. The other examples cover specific case studies and applications of *Atmodeller*, and :doc:`updating_models` shows how to solve a model efficiently in a loop.
